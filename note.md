#### Quá trình bài test tự động thực hiện và chứng minh:
1. **Khởi tạo Nhiều Database (Multi-DB Creation):**
   - Deploy **Contract 1** (`SharedUpdate`) $\rightarrow$ Khởi tạo DB `blockstm_shared_xapian`.
   - Deploy **Contract 2** (`TestFullDBV1`) $\rightarrow$ Khởi tạo DB `products_test_v1_version1` và index 3 documents (iPhone, Samsung, Macbook).
2. **Ghi và Mã hóa Lưu xuống SSD:**

     ```text
     /data/local/tmp/xapian_storage/<Contract_1_Address>/blockstm_shared_xapian/wal.log
     ```

4. **Chọn đúng 1 DB để Load vào TEE (Selective Load):**

5. **Truy vấn DB vừa Load:**
